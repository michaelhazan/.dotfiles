# revdiff

This package contains configuration for `revdiff`, a TUI for reviewing diffs with inline annotations.

The colors are taken from the `catppuccin-mocha` highlight groups used in the `nvim` package (`DiffAdd`, `DiffDelete`, `CursorLine`, `Search`, etc.), so reviewing in `revdiff` looks the same as in `nvim`.

[See more here](https://github.com/umputun/revdiff).
